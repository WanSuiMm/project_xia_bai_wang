# 自然语言资料集与后续交互研究

## 已确定的研究范围

- 冻结 LLM 参数，不进行 SFT、LoRA 或策略训练。
- 保留真实 Reader、战略 Bluffer、Judge，多轮自然语言提问、回答、历史依赖与停止。
- 主模型配置为 `qwen3.8-max` Speakers → `glm-5.3` Judge，以及反向配置。同局 Reader/Bluffer 同模型，独立会话；模型名称是请求标签，正式接口可用性尚未在本批核验。
- JES32、OSI48 等已知机制题保持历史证据身份，不作为自然语言主实验或混入自然语言样本量。
- 本次只构建开发资料与离线工具，未启动付费调用或 GitHub 发布。

## 本批与完整研究的关系

本批 24 个创作世界覆盖 ecology_fieldwork、materials_engineering、archaeology_conservation、civic_institutions、ethnography_social、linguistics_fieldwork、mathematics_practice、investigations_history。它们属于可读的开发集，用于检查资料结构、角色路由、语义编码和后续完整对局的成本。它们不能在看过对局结果后升级为未见过的确认性测试集。

正式数据建设仍保留约 200–300 个独立世界的规划目标，但不是当前已批准运行量或固定 power 结论。最终规模需在预先选定最小有意义效应、开发集方差、预算和缺失处理后冻结。若同一事实骨架被改写或生成反事实版本，所有版本共享 family/group ID，不能算新增独立世界。

`family_id` 是追踪结构复用的起点，唯一 ID 不证明 iid 或领域外泛化。本批材料由 AI 辅助编写，不是来自真实档案，也未进行独立人工双编码。后续需要独立语义复核；语法检查通过不能称为科学资格通过。

## 每个世界的内容

公共背景只给熟悉 ontology 与题材，不给私人事实、来源边界表或 Reader 座位。有限 source 有具体事实、明确否定、跨事实依赖、归因与自然缺口。所有答案保持自由文本。

Host-only evaluation 保存以下记录：

- supported_claims / explicit_negatives：每项附精确来源子串；来源没写不等于明确否定。
- licensed_inferences：列出前提和有限推断，不伪装为原文事实。
- unspecified_probes：相同主题的中性问题、植入候选前提的问题、候选断言和缺口说明。
- consistency_questions：开放问题与至少两条来源关系的参考说明。

这些记录定义有限评估切片，不是完整世界真理，也不是 Judge 的可选 query 菜单。自由问题若超出标注范围，需要新增带来源依据的编码，保留歧义，不能由词面匹配自动判正确。

## 提示与角色指令混淆

`matched_access` 使用同一获胜目标与公共表达规则，仅私有材料可得性不同。允许两方表达不确定、拒绝前提或给出具体叙述；没有要求 Bluffer 每问必答或 Reader 每问都说“不知道”。这减少明显指令差异，但不保证所有角色效应已消除。

另外保留 `strong`、`boundary_aware` 对手指令及 `source_faithful` Reader 指令作为显式条件。不得把 matched_access Reader 与 source_faithful Reader 混在一起估计纯访问效应，或把不同 prompt 视为经过证明的战略强度排序。对手未收到真实 source 或边界地图。

本批未预造 Frozen counterfeit。后续如做此条件，应在未知真 source 的条件下独立生成并冻结假资料，保留生成机制。仅仅说“两方都持有资料”并不能宣称同分布或不可识别。随机 target Frozen 与真实来源访问属于不同估计对象，分别分析。

## 后续主要比较

主比较候选是同世界、同模型方向、同对手条件下 Active 与 Nonadaptive 的最终决策损失差。Nonadaptive 先依据同一公共背景提交自然语言问题计划，不能看后续回答改问题；双方仍需分别产生真实完整对话。Active 只依据可见历史选择问题和对象，自行停止。不能用同一条冻结 transcript 冒充两种提问政策的反事实表现。

问题与对手策略可以影响后续回答，正是研究对象。固定历史的假前提机制实验应另作随机分支，对同一前缀分配中性与候选前提问题，再独立继续两席，不把自然出现的机会当成随机因果干预。

不固定问满若干轮，也不恢复此前五次 ASK 上限。共同配置通过相同总生成资源保护界防止无限调用；达到保护界应标为预算截尾，不能冒充 Judge 自愿停止或弃权。具体资源数值与计费控制需要在 launch protocol 中核验、冻结。

## 评价与数学对象

Host 知道实际 access seat，可以按实现的身份标签评价 Brier、错误/弃权损失。Host 不因此知道任意自然语言历史的真实 posterior、TV、KL、MI 或 Bayes 最优提问。

预注册主要终点应按 world/family 计算配对损失，并报告覆盖率、成本、缺失和方向分层。回合、句子、座位交换及同世界重复均是嵌套观测。确定性角色路由与来源忠实度是机制检查；它们不是来源身份已可认证的证明。

冻结的、仅读取 Judge 可见信息的参考判别规则可以给出可分性下界；测试集上低准确率不能给出不可识别性的证明。参考判别器或提示策略不等于 Bayes oracle。关于 inference gap / interrogation gap 的精确分解保留为理论对象，经验比较只是可观测的参考差，不能把差值直接命名为精确理论 gap。

## 从附件采纳与修正

采纳附件的 training-free、完整对话分布、战略生成、信息获取和决策风险主线。经典界的条件与估计难度保留，不能因为有更多公式而宣称已估计语言分布。

在给定固定对手与共同机制时，理想主动策略类包含固定策略才有最优风险的弱支配；实际两个 LLM 政策的收益仍须测量。对手改变时，须明确固定策略、响应还是最佳响应模型。`beta*(pi)` 是建模记号，不能把一次提示后的回答称为已求得的最佳响应或均衡。

若固定总轮数 T，`lambda*T` 为常数，不会解释自主停止。后续使用实际停止成本 C_tau（请求、token 或时间的预注册口径）。Bhattacharyya/Hellinger 指数界需要对全部相关历史的条件 affinity 控制；不从少量文本相似度评分假定该条件成立。

## 正式采集前的必要冻结项

独立测试世界及分组规则、具体条件/交叉或平衡分配、每世界重复数、角色座位与顺序随机化、推理/输出/总成本预算、模型返回标签验证、失败恢复规则、参考策略与主要终点。配置核验以接口支持为由修订，不能根据结果挑选较好的配置。上述待办不缩减完整研究问题。
