## 已知的检查限制

当前容器的 Chromium 策略阻止 file:// 和 localhost 页面导航，所以浏览器交互测试采用 `set_content` 载入同一完整 HTML。**没有在此环境确认“直接双击文件后的 localStorage 跨重启持久性”**。页面对此有异常处理；每题导出 JSON 是可靠备份。数据恢复通过 JSON 导入已测试。

浏览器复制权限也可能因环境不同；若自动复制被拒绝，页面选中文本，可手工 Ctrl+C。没有把此检查说成各浏览器/各操作系统全兼容认证。

## 源代码与重建

`tools/regenerate_data.py --output <空目录>` 重新生成冻结数据、提示词和文档；它不重新安装工具，也不自动生成一个新的实验版本。
`python tools/build_console.py` 根据包内 console_bundle 和 console.js 重建根目录 HTML。
`python -m unittest discover -s tests -p "test_*.py" -v` 运行标准库测试。
`node tests/test_console.js` 运行可选的前端开发测试。

页面保留回答首次记录及之后替换的 before/after 事件。修改过的原文必须人工审查，不能把格式修理变成补造内容。分析器会对原文替换给出警告；它不会自动把这些更改判为诚实或不诚实。
