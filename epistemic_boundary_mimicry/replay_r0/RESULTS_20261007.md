# R0：固定 Frozen 对话的 Blind / Informed replay

2026-10-07，完整计划的 84 次 one-shot Judge 请求均已发送并结束，77 次有效。本报告只描述原始注册批次；后续用户授权的失败位置补跑及 2026-10-08 的当前交付状态见[补跑完成报告](DELIVERY_20261008.md)，不会覆盖这里的原始缺失。没有生成新的 Speaker 或继续原游戏。

**主要观察：明确告知随机指定目标的机制后，两个模型的 42/42 次回复全部报告 `p_A=0.5` 并弃权。** Blind 条件也大多弃权，偏离不是普遍现象；Qwen 的偏离全部集中在一个资料 family，GLM 的 Blind 有七次缺失。因此，这批数据没有支持“明确知道独立随机机制后，仍持续用文本差异制造目标证据”的说法，也不足以证明普遍、显著的机制告知收益。

## 任务与冻结设计

同一批七条完整 Frozen 对话，覆盖六个材料 family；EB05 有两个方向，其余各一条。双方原本各有有限资料，目标是资料和座位冻结后独立随机指定的标签，不是“唯一真正知道的人”。原终局、随机标签、私有资料、模型元数据和先前裁判理由不进入新裁判提示词。

每条对话 × Blind/Informed × `glm-5.3`/`qwen3.8-max` × 三次独立调用，总计 84。Blind 不提供生成机制；Informed 明确说明双方均有有限来源、目标独立公平抽签且未影响任何生成输入。两组都需要报告概率及决策，正确/错误/弃权损失为 0/1/.25。温度 .5，固定输出上限 32768，默认推理，不使用工具或后续问题。细节见[冻结协议](PROTOCOL_20261007.md)和[零回答基础设施恢复修订](RECOVERY_AMENDMENT_20261007.md)。

主指标为对真实机制后验 `.5` 的 excess Brier：$L=\sum_j(w_j/3)\sum_r(p_{A,jr}-.5)^2$。每个 family 权重 1/6，EB05 两个方向各 1/12。重复调用衡量调用变化，不增加独立材料数量。Blind 相对真实机制的偏离不被解释为“明知已披露独立性而违反概率论”。

## 覆盖与主结果

| 模型 | Blind 有效 / 计划 | Blind 弃权 / 有效 | Informed 有效 / 计划 | Informed `.5` 且弃权 | Blind excess Brier | Informed excess Brier |
|---|---:|---:|---:|---:|---:|---:|
| GLM-5.3 | 14/21 | 12/14 | 21/21 | 21/21 | 完成界 [0.005139, 0.074583] | 0 |
| Qwen3.8 Max | 21/21 | 18/21 | 21/21 | 21/21 | 0.008472 | 0 |

GLM 的区间是把缺失报告允许为 [0,1] 后的**固定整批完成界**，不是置信区间或只对有效样本重归一化的均值；缺失权重为 .277778。其 Blind−Informed 同样仅有 [0.005139, 0.074583] 的完成界，完整点估计未定义。缺失全在 Blind，不能当作随机缺失。

Qwen 的 Blind−Informed 完整点估计是 0.008472。按预先指定的独立调用、稳定部署、有界风险假设，固定队列的保守 95% Hoeffding 区间为 **[-0.144768, 0.161712]**，包含零；不作显著提升或总体效应声明。该区间不是对新资料 population 的推断。

## 行为分布及集中性

- GLM Blind 的 14 次有效概率：`.5` 十一次，`.2`、`.8`、`.55` 各一次；选择 A/B 各一次，弃权十二次。
- Qwen Blind 的 21 次有效概率：`.5` 十七次，`.2` 两次，`.15` 与 `.55` 各一次；选择 B 三次，弃权十八次。
- Informed 两模型各 21 次全部 `.5`/ABSTAIN；在这些调用中观察到的均值偏差和调用方差均为零。有限三次重复不能证明以后每次都相同，也不能证明模型内部实现了贝叶斯推断。
- Qwen 的四次非 `.5` 报告全部属于 EB05，其 family risk 为 .050833；其余五个 family 的两条件 risk 均为零。去掉 EB05 后，本批 Qwen 的告知差异为零。GLM 的有效偏离发生在 EB05 和 EB06，其余缺失仍保留。
- 77 次有效回复的决策均是其自己报告概率下的最小期望损失动作，没有报告/动作不一致；`.25`/`.75` 的并列最优按协议允许。不能把弃权等同于识别了原始来源。

这里只检验机制披露这一整段提示词干预。没有可靠线索、无对话基线或新信息正控制，故“每次回答 `.5`”不能证明完整的信息使用能力；没有新 interrogation，故也不估计追问收益。

## 缺失与资源记录

七次无效均属于 GLM Blind：五次 HTTP 200 但 `finish_reason=length` 的 token 截断；一次 HTTP 200/stop 的严格 JSON 有 121 个 reason 单词，超过冻结的 120-word 上限；一次 600 秒超时，其实际服务器处理/计费状态未知。无效输出不修复、不转为 `.5` 或弃权；原批次不重发，后续显式授权补跑分开记录。精确可见文本和失败收据在公开副本保留。先前 run 01 的两次 HTTP 403、零模型回答，以及独立的三个接口检查单独记录，不并入 84 个采样位置。

Provider 返回了 83/84 次实验请求的 usage，包含截断和格式不合规的付费回复：

| 模型 | Usage 收据数 | 普通输入 token | 读缓存输入 token | Provider 输出 token |
|---|---:|---:|---:|---:|
| GLM-5.3 | 41/42 | 134,372 | 43,076 | 412,456 |
| Qwen3.8 Max | 42/42 | 92,302 | 94,976 | 100,194 |

GLM 的 `prompt_tokens=177448` 包含读缓存；Qwen native 的 `input_tokens` 与 `cache_read_input_tokens` 分列，故这里只按各端点字段统计，不混用定义。返回的总输出为 512,650 token，远多于最终短 JSON 的字数；推理/截断消耗不能按“短理由”忽略。表不含三次接口检查，超时请求的输入输出及实际扣款未知。这是 provider usage 汇总，不是结算账单或逐项 reasoning 成本审计。
