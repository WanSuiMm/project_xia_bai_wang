## What this delivery contains

Sixteen fresh GLM-5.3 behavior forecasts on eight old Qwen3.8-max target prompts, with two independent repeats, all strict-valid. Public evidence includes exact model-facing prompts, visible replies and parsed probabilities, safe dispatch receipts, frozen input/code hashes and reproduced descriptive analysis. The first failed HTTP 403/payment request and subsequent identical-design recovery remain distinct. Private account/session/launch information, credentials, headers, raw error bodies and hidden reasoning are excluded.

The equal-family mean prediction for an explicit requested-detail source-silence admission increases from .0373 to .1292 after historical Judge-evaluation exposure. All individual probabilities remain below .5. The four-family contrast is uneven and largely driven by SQ04. Old target answers contain 47 clear non-admissions and one unresolved event. Primary paired complete-case Brier change is +.0259 across three families; both hypothetical ambiguity resolutions are included without changing the original coding.

This does not establish pervasive over-attribution, true-probability miscalibration, an internal opponent model or an explanation of SQ03's identity error. There is one old Actor draw per family-condition. Two forecast repeats do not add Actor outcomes. This hypothesis-guided retrospective replay was selected after viewing SQ28. Earlier experiments, sources, failures and theoretical claims are unchanged; no R1 or new full game was run.

## Reproduce without an API key

Python 3.10+ and the standard library are sufficient. From the standalone repository root:

```text
python -X utf8 -B scripts/publish_opponent_model_replay.py
```

The default command validates only repository/public files, reconstructs prompts, re-parses exact visible JSON, checks source/coding and safe-copy hashes, and reproduces all descriptive aggregates. It neither contacts a provider nor reads credentials. `--export` is only for the original private completed run; a fresh GitHub checkout should use the default public audit.

The private initial partial Markdown export is retained locally. Its renderer correction affects neither collected outputs nor scientific configuration. The canonical local analysis was generated separately in `analysis_complete`; publication uses that completed analysis, with source hashes distinguished from sanitized public-copy hashes.

Frozen preparation and launch documents describe their historical authorization and incomplete launch snapshot. This delivery supersedes their status statements about publication and completion; it does not rewrite them.
