Sources were sampled separately from the same template-based generator, then frozen. Seats were randomized and frozen before independent target designation. Both readers had finite sources and equal instructions. The Judge saw public context and requested visible answers only, with no Host truth, opening, READY or ASK cap. The Judge was not told the random-label mechanism. Target matching would not measure authenticity inference; abstention has no correctness score.

EB03's Judge described similarly bounded, consistent accounts with no clue connecting one set of names/counts to the target. EB04's Judge noticed almost identical prose structure and stable quotations with substituted facts and called selection a coin flip. These are stated reasons, not verified causal mechanisms. Shared template wording is an obvious cue; these results do not establish the same behavior with independently authored counterfeit dossiers.
