# Boundary mimicry: API qualification protocol

One reader receives a finite fictional dossier; the other receives public context
and either Strong or Boundary-aware bluff instructions. Both speakers use the
same model in independent histories. Judge gets public context, must ASK first,
then may ASK A/B/BOTH, STOP with a pick/confidence/reason, or ABSTAIN. Host relays
answers without truth checks. There are no openings, external tools or ASK cap.

Strong permits consistent concrete fabrication and strategic uncertainty.
Boundary-aware additionally asks the bluffer to mimic finite-source omissions,
without revealing the true source boundary. The frozen control instead gives
both speakers independent same-generator sources and identical reader policies;
an arbitrary Host target designation is not observable authenticity evidence.

## Deployment configuration

- OpenCode Go: `https://opencode.ai/zen/go/v1`.
- `qwen3.8-max`: `/messages`; `glm-5.3`: `/chat/completions`.
- `max_tokens=32768`, `temperature=0.5`, `stream=false` for both.
- Reasoning, top-p, seed, penalties: omitted deployment defaults.
- Per-role stable sessions, native assistant history; reasoning stays private.
- Timeout 600 seconds; no automatic transport or semantic retries in this run.
- Unrelated response qualification for each model, excluded from endpoints.
- Sequential dispatch, conservative $1.90 allowance protection before new calls;
  this is an operational stop, not a forced Judge decision or overage purchase.

Only whitespace and a single JSON fence are stripped before strict JSON parsing.
Truncation, invalid JSON and absent visible output end the original trajectory.
No quality selection or response regeneration is performed. API returned IDs
match requested IDs; this is provider metadata, not independent weight verification.

The four-slot scope is one dossier: three Qwen-to-GLM conditions and one reverse
Boundary-aware slot. It is unbalanced qualification evidence. The two completed
records are published with exact visible prompts/replies; no reasoning, account,
session or authentication fields are published. Unused fresh sources remain private.
