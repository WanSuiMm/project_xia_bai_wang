两条报告均精确等于对应理论后验，动作也最小化给定损失。协议不抽取一个实际身份标签评分，因此这里是“后验符合 oracle、动作损失最优”，不是两次验证了真实 Reader 身份。

## 第三条 GLM 请求能说明什么

请求 OSI_GLM_REFRESHED_H4_ONESA_R2 的收据保留：

- HTTP 200；status 为 invalid_provider_response；error_type 为 ValueError。
- 没有保存到可见回答、解析值、返回模型 ID、finish reason 或 usage。

采集器在 JSON 解码或提取预期响应字段时都可能触发 ValueError。原始 provider envelope 和异常正文未保留，无法确定是响应结构、空内容、缺少字段还是其他解析问题；也不能把它说成模型答错、拒答、推理截断或额度耗尽。

这是接口／采集完整性失败，不是一个可评分的 GLM 行为结果。没有自动重试，也没有因答案好坏替换样本。
