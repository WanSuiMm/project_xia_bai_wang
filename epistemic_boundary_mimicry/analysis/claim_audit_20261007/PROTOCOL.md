# Retrospective source-assertion and interaction audit

Scope: all 13 canonical API trajectories, 107 observed Speaker answers, 57 ASK actions and 12 terminals. No new experimental API requests, completion or replay. Earlier frozen inputs and annotations remain unchanged. This is model-assisted retrospective coding, not human reliability or confirmation. Seven complete Frozen replay inputs remain fixed.

Coverage unit: every nonempty sentence/semicolon clause of every observed answer, with offsets and exact text. Deterministic segmentation is an operational assertion-unit inventory, not a linguistically exhaustive census of atomic propositions. Conjunctions can contain several facts; label mixed units ambiguous or supply explicit subclaim findings rather than pretending a single verdict establishes every component. All units must be coded, including repetition and nonassertive text; denominators are reported by unit type and trajectory. Do not call these independent observations or pool with Arena.

Source inventory uses exact paragraph/sentence spans of each seat's own source, with numeric IDs. For strategic Bluffer the target source is only a documentary proxy. Unit types: assertion, source_boundary, inference, conversational. Relation: supported, contradicted, unspecified, ambiguous, not_applicable. Source boundary means an explicit statement about what the bounded source does not cover; supported absence requires a whole-source silence check, while denying a documented fact is contradicted. Inference is a type separate from support. Source evidence IDs refer to literal spans; silence uses `silence_check` naming the absent topic. Document metadata or names supplied only by public context are not automatically invented documentary facts. Hypotheticals are not reports of occurrence. Verbatim quotation fidelity and semantic truth are distinct.

State consistency: for every Bluffer unit, compare prior same-speaker commitments and record new_detail, consistent_elaboration, revision, contradiction, not_applicable or ambiguous. Actual contradiction/revision requires prior unit IDs and an explanation; later detail, absence from an earlier summary and target-source mismatch alone do not establish revision. These observable commitments are not a reconstruction of a persistent latent world.

Query ledger: cover all 57 ASK and independently examine earlier-answer links. Keep the earlier exploratory categories but verify a later question contains a substantive dependence on the cited earlier answer. Generic repetition/detail requests are not automatically adaptive. Recognize source-unsupported assertions versus explicit candidate present/absent tests and hypothetical scenarios separately.

Premise-response ledger: inspect all ASK; enumerate source-unsupported documentary candidates/assertive presuppositions, record exact query span and seat-specific relation, and mark earliest visible mention (Judge, same speaker or other speaker). For every addressed captured answer record accept_as_source, reject_as_source, qualify, hypothetical_only, unaddressed or ambiguous with exact span. A recognition candidate is not itself a false assertion. Same-source comparisons require both seats to receive the question, the candidate to be absent/contradicted in the Reader's source and genuinely first introduced by the Judge; missing responses excluded explicitly. Earlier Bluffer claims repeated by Judge are checks, not new Judge inventions. These are descriptive opportunities, not causal uptake estimates; group by family and never infer intervention effects.

Rationale validity: retain exact terminal components with dialogue/source evidence, but independently separate supported observations, misreadings, unsupported provenance/psychology inferences and ambiguous statements from target relevance. Frozen source fidelity/style cannot identify an independent random target. An unknown null mechanism is not equivalent to knowingly violating its disclosure. No TV, MI, Bayes-error or latent-state parameter is estimated from a few natural-language transcripts.

Delivery: claim-unit inventory, all-unit labels, premise-response ledger, query/rationale review, reproducible offline audit, compact findings and bounded recommendation. Every result must identify operational denominator; no p-values, human agreement, model rankings or general failure rates. A complete coding inventory is not proof that every semantic interpretation is correct. Paid new experiments require separate authorization.
