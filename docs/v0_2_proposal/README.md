## 我的判断

**支持作为下一版候选方向，但不支持目前就认定它解决了可辨识性问题，或认定 grounding 会提高裁判准确率。**

它的优点很具体：不必搭建完整新世界，保留熟悉领域里的推理工具，同时随机决定本局的新定义或事实。追问可以要求应用、反例和边界条件，而不只是复述八项标签。数学与语言学尤其容易预先写出可核验答案；历史和人类学更接近自然交流，但解释空间更大。

需要修正一个关于 v0.1 的前提：三道完整题不足以证明“质询没用”。v0.1 本来也允许反事实组合问题；区别应是推理内容与约束结构，而不是简单地把旧版说成背 bit、新版说成推理。

## 关键限制与修改

### 1. 背景约束不等于本局真值证据

如果知情者按定义 F 作答，未知情者按另一套同样合理的定义 G 作答，两者都能保持一致，熟悉图论或历史制度仍未必能告诉裁判本局抽中的是 F 还是 G。Grounding 可能暴露执行错误、编造时的不一致或先验偏好，但不会自动消除 v0.1 的交换对称性。

因此主问题应写成：“在这些配对卡上，后果与边界问题是否产生可用于识别初始卡片访问的信号？”不应写成：“只要嵌入现实知识，就能分辨 genuine knowledge 与 fabrication。”继续保留 N/E 独立证据对照，并单独记录知情者的推导正确性。

### 2. 配对必须完整，不能按结果选择补跑

第二份原文前面要求两种真值都跑，后面却建议先跑 A、只有出现信号才跑 B。这会让配对覆盖取决于观察结果。工程练习可以只跑一张卡，但不计入发现结果；正式小试必须提前选定完整 pairs，无论第一种真值表现怎样都跑另一种。

真值版本标签与玩家座位 A/B 是两套变量。正式数据建议用 V1/V2 标记版本，另外独立随机分配知情座位。配对版本使用隔离的新会话，不让模型看见另一版本或配对关系。

配对平衡可揭示固定先验偏好，不能保证所有混杂被抵消：两版本的复杂度、语言长度、可推导性和错误率仍可能不同。

### 3. “新名字”不能证明训练记忆绝不命中

随机命名和检索只能降低直接实体记忆命中的风险；检索不到也不是不存在的证明。关键保护来自实验前随机确定私有事实，并平衡真值版本。已有概念和相似定义仍可能见过。Prior-only probe 用来测公开背景的可猜性，不等于泄漏检测；先验偏斜的题可保留为诊断，但不能观察结果后悄悄筛掉。

### 4. 先把可核验性写清楚

预先固定三个检查输入及各版本答案，要求双方开场作出冻结承诺。检查应包含能区分版本的输入，也包含双方一致的输入；N 不看答案，E 看真实结果。若双方承诺碰巧都对，或知情者推导出错，单独报告，不能把该局当作明确可诊断的正对照。

不要直接把示例中的 useful interrogation directions 只给某个角色；它们可能泄露私有定义。题库设计者可用它们检查题目，但裁判只接受统一的后果、边界、反事实提问要求。

### 5. 候选卡还需消歧

- Selvar：明确只收缩一条边，选边后不继续迭代，并处理收缩产生的自环和重边。V1 的“恰好一个诱导奇环”已蕴含非桥，非桥条件是冗余的。V2 不能简称为“偶环版”：它排除属于任何诱导奇环的边，具体条件比名字更严格。
- Serevic：明确“after a stressed syllable”是否指紧邻前一个重读音节，给出音节划分及重音记法，并说明规则是否一次同时应用，避免连锁应用歧义。
- Taluma / Varen：区分档案明确给出的事实、逻辑蕴含与仅仅合理的社会解释。无法唯一推出的后果不能作为硬真值评分。
- Orava：明确“需要某处理”是必要条件、充分条件，还是二者兼有；固定其他生长条件与观测时间，避免把萌发预测解释成任意概率。

## 建议的最小下一步（尚未授权执行）

**Go：保存方案并设计一个可核验的完整数学 pair。No-go：现在同时铺开五领域，或直接宣称 grounding 的因果效果。**

最小流程试验是 Selvar 的 V1/V2 两张卡，使用同一 speaker/judge 配置、独立会话和事前随机知情座位。三项冻结检查可用树、C4、C5：树在两版本均无 eligible edge；C4 在 V1 无、V2 有；C5 在 V1 有、V2 无。分别要求初始承诺，随后三轮追问，再运行独立 N/E 裁判。两局共 28 次回复，另需记录公开背景 prior-only 探测；准确流程以之后冻结的协议为准。

先进行一次小的确定性答案与提示词隔离检查，再进行模型流程试验。执行前需另行授权、冻结版本与问题；此次没有发出任何新模型请求。预留一次人工操作窗口，不安排持续监控；所需时长取决于平台延迟，不能从次数推断已完成时间。

流程停止标准：匿名候选身份无法核实、会话信息串流或答案泄漏时，保留污染记录并停止该局；题面出现两种合理评分解释时，停止并修订到新版本；不因模型答错而 regenerate。若 E 有明确区分性证据却处理失败，先判断是题目/采集问题还是模型证据使用失败，不扩大题量掩盖问题。

两局只足够检查是否可执行，不能证明能力提升或领域差异。之后若要研究效果，以预先选择的完整 pair 为分析单位，报告每局和每对结果、P0/P3 变化、N/E、知情者推导错误和 prior-only 偏好；十张卡实际只有五个背景 pair，不能把轮次或回答当作独立样本。

## 若要研究 grounding 的因果效果

U/C/G 是另一个尚未冻结的实验。它需要保持同一私有事实、角色目标与回答预算，明确操纵哪些公共事实，并控制提示词长度和泄漏。跨五领域的准确率差异不能直接归因于 grounding；P3-P0 也同时包含更多文本和交互。要归因于主动质询，还需匹配文本预算的被动对照。

下一版的合理定位是“发现性卡片与协议”，不是已验证 benchmark，也不是一般 ToM 或现实谎言检测能力测试。
