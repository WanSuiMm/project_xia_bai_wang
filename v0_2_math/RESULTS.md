## 内容与解释

两个版本共享“图中哪些边可以收缩”的公开背景，私人规则不同。三个初始预测分别是路径 P3、四边形 C4、五边形 C5 能否找到合法边。

|版本|真实规则|真实 Q1/Q2/Q3|知情者预测|未知情者预测|
|---|---|---|---|---|
|V1|非桥，且恰好位于一个诱导奇环|FAIL / FAIL / PASS|全对|PASS / FAIL / PASS|
|V2|非桥，在某个环上，且不在任何诱导奇环上|FAIL / PASS / FAIL|全对|PASS / PASS / FAIL|

独立环枚举检查通过；两版未知情者都只在 Q1 与真值不同，没有初始预测碰撞。public-only prior 给三项 PASS 概率均为 0.5，并报告证据不足；单次回答不证明无泄漏或良好校准。

V1 未知情者开场声称收缩奇环边后保持相同奇偶性，这一数学说法错误；P0 裁判明确依靠这个错误偏向 A。双方随后对 K4 的回答各自符合所声称的规则，但没有 P1 可供分析。

V2 未知情 A 声称“桥或诱导四环上的边可收缩”。三轮分别询问 C6、四边形与三角形共边、三角形接桥。A/B 均维持各自规则的内部一致性，未出现可用的逻辑破绽。交互裁判主要因为 B 的规则与公开词汇 bridge/cycle/induced cycle 更契合而偏向 B。

N 没有独立真值，却以同样词汇契合理由判定证据足够；这不能证实初始卡片访问。E 则看到三个真实结果，并指出 B 初始预测全对、A 的 Q1 错误，提供了独立验证依据。不过未知情者仍可能猜中，90% 也不是访问记录的证明。
