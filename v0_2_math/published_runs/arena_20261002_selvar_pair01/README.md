# Published evidence

Read ../../RESULTS.md first, then ../../PROTOCOL.md and ../../analysis.json. These records contain host answers and private role prompts; do not forward an entire log to a tested role.

The logs preserve exact prompts, raw JSON replies, failed-send event types and platform intervention steps. Publication omits UI DOM (including anonymous candidates), account information, private conversation URLs, screenshots and browser handles. Hashes bind the published prompt and reply strings to the local originals. Missing responses remain missing; no model error is inferred from a platform failure.
